# Changelog

## 1.0.0

- Portable Windows x64 read-only monitor, trainer IDs, lead Synchronize detection, generated-roamer display and target tracking.
- Exact-hash profiles for 0.1.12 and 0.1.13, with per-build evidence levels stated explicitly.
- Local browser predictor for stationary Method J, first Cresselia/Mesprit releases and context-aware Oak bird releases.
- GitHub Pages walkthrough, Journal advance measurement, source and monitor downloads on one page.
- No gameplay automation, memory writes, save editing, snapshot uploads or game assets.

Known limits: fresh 0.1.13 encounter calibration, Synchronize hunt calibration and Oak re-release verification remain open. Starter manipulation and unknown encounters are not supported.
