KEEP THIS OPEN WHILE YOU HUNT

The full Journal walkthrough

  1. Save before the legendary is generated

    For stationary encounters, stand directly in front of it without interacting. For Cresselia and Mesprit, save before speaking to them: their release fixes the roaming Pokémon’s identity. For birds, save before talking to Oak.

  2. Check that the monitor supports your build

    Load your save, connect, and confirm the trainer IDs look right. The app checks the executable’s full SHA-256 and loaded RNG function. After a game update, an unknown hash means stop and wait for a verified profile.

  3. Measure your Journal pages

    Open the Journal. Note the seed, turn one page, and compare the RNG count. Two is common on our tested battle/catch pages, but some pages give zero. To measure directly, enter the before/after seeds below. Test both directions. Don’t assume every page turn counts.

  4. Import a fresh snapshot and search

    Keep the Journal open while copying the snapshot. Use the correct encounter mode. Stationary Synchronize depends on the lead’s ability and nature; the monitor fills it in when it can read the lead. Oak’s mode needs the full snapshot so it knows which birds will be released.

  5. Track your chosen target

    Click Track in monitor beside a result, then Paste target from predictor in the Windows app. Turn pages while watching actual remaining advances. If the count changes unexpectedly or you pass the target, stop and calculate again.

  6. Close, recheck, interact

    At zero, close the Journal, Bag, and menu. Confirm zero again. Our tested locations consumed no calls during closing; other locations may differ. Interact immediately. Check the actual Pokémon, catch it, and save normally. For a roaming release, check the monitor’s generated-roamer table and save after a successful release.

A FEW IMPORTANT DETAILS

Before you reset.

Does the website connect to my game?

No. Browsers cannot read another app’s memory. The Windows monitor reads it locally; you explicitly copy the snapshot here. The page makes no snapshot uploads and has no analytics.

Is this a cheat or a save editor?

The app requests only process-query and read permissions. It has no memory-write, injection, gameplay-input, or save-edit features. It does expose hidden game state; decide whether that fits your own rules.

What if no nearby target appears?

Expand the search range or use the game’s normal Ctrl+R reset to get another seed. Reconnect after reset and copy a new snapshot. The PC game mixes extra randomness into seeding, so a DS launch timer cannot reliably select a seed.

How do Oak’s bird re-releases work?

Catch your shiny bird. Knock out the nonshiny birds you want to reroll, then beat the League after those knockouts. Return to Oak and save before speaking. The snapshot identifies the birds eligible for re-release. Already caught birds stay caught. Re-release predictions are experimental until independently calibrated on your exact build and state.

Can this manipulate starters?

Not in this release. Shiny starters are possible (normal odds 1/8,192), but the chooser caches three PID rolls when it opens. A fresh game usually has no Journal yet. The starter transition needs its own calibration; the legendary predictor is not a starter predictor.

What are the limits of the predictions?

Historical calibration covers the listed 0.1.12 encounters with offset 0 for stationary Method J and offset 4 for the first Cresselia/Mesprit release. Oak’s initial release matched all three generated PIDs. 0.1.13’s read-only memory layout is verified, but new encounter calibration and repeat-release tests remain open. Unknown gifts, eggs, battles, species, or locations may use different generation rules.

Why did the monitor disconnect?

Ctrl+R starts another game process. Click Connect again after loading. Run exactly one game copy. If your executable hash is unsupported, don’t disable the check; open an issue with the game version and hash. Never post a save or snapshot publicly unless you intend to share the trainer information in it.
